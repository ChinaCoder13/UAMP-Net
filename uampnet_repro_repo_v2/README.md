# UAMP-Net Reproducibility Repository

This repository contains a paper-aligned implementation skeleton and deterministic
smoke-test artifact generator for:

**UAMP-Net: Uncertainty-Aware Activation-Guided Multi-Prototype Pattern Mining for Explainable Fine-Grained Visual Recognition**

The code follows the manuscript pipeline:
1. Backbone feature extraction
2. Activation response map generation
3. High-response local region selection
4. Local descriptor extraction
5. Class-wise descriptor banks
6. Variational Bayesian Gaussian mixture prototype discovery
7. Reliability and uncertainty scoring
8. Global-prototype fusion
9. Classification, explainability, uncertainty, and efficiency reporting

## Important transparency note

The pre-filled files under `outputs/`, `checkpoints/`, and `prototypes/` are deterministic
smoke-test artifacts generated by the repository's scripts. They are included so the
repository has a complete runnable shape and produces all manuscript-style figures/tables.
For an actual reproducibility release, replace these artifacts by running the scripts on
PlantVillage, PlantDoc, and CUB-200-2011.

## Quick smoke-test run

```bash
python generate_demo_artifacts.py --config configs/uampnet_paper.yaml
python evaluate_and_report.py --config configs/uampnet_paper.yaml --use-existing-artifacts
```
