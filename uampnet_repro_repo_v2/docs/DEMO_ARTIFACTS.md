# Demo artifact disclosure

The files preloaded into this repository under `outputs/`, `checkpoints/`, and
`prototypes/` are deterministic smoke-test artifacts created from configuration and
synthetic numeric streams. They are included to show the complete output structure
and to let users regenerate all manuscript-style result figures/tables without
downloading datasets.

They are not a substitute for real training results. For paper release, rerun the
repository on the real datasets and replace these artifacts.
